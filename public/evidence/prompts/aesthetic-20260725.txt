# 任务：为虚构机械键盘「声律 75」制作产品发布页

【设计意图】
这是一次前端审美能力的专项测试。你要为一款虚构的机械键盘做一个**炫酷、动感、有高级感**的单页产品发布页——大胆使用 3D 视角展示、视差滚动、光影、粒子等表现手法，做出发布会级的视觉冲击，同时保持品味、可读性与克制（炫酷不等于乱闪）。没有任何现成素材图——页面里的一切视觉元素（键盘造型、材质质感、配色展示、图标）都必须程序化构建。审美即考点：视觉冲击力、3D 与动感表达、排版功力、造物质感。动手前先用一句话复述你理解的任务边界，然后直接继续完成，不要等待回复。

【产品设定（事实钉死，不得更改或添加）】
- 品牌：声律 SOUNDRHYTHM（虚构品牌）
- 产品：声律 75 —— 75% 配列机械键盘
- 三大卖点：
  1. Gasket 结构 + 五层消音棉，敲击声线干净低沉
  2. CNC 一体成型铝合金机身，五种配色（暮山紫 / 月白 / 黛青 / 胭脂 / 玄墨）
  3. 三模连接（有线 / 2.4G / 蓝牙5.3），满电续航 30 天
- 售价：¥1299，发布日期 2026 年 8 月 8 日
- 禁止出现任何真实键盘品牌名、真实产品照片或商标联想

【任务】
1. 单页发布页，交付 `index.html`、`styles.css`、`app.js` 三件，本地 HTTP 打开即用
2. 四个固定 id 的区块（顺序自定，视觉结构自定）：`#hero`（首屏）、`#features`（卖点）、`#colors`（配色展示）、`#buy`（购买 CTA，虚构按钮不得跳转外部）
3. 页面中必须出现程序化构建的键盘视觉主体，**鼓励 3D 表现**（CSS 3D transforms / Canvas / 原生 WebGL / 预置的 `vendor/three.min.js` r147 任选，不强制用 3D 但立体质感是重要考点）；配色展示区五色可切换且键盘视觉随之联动
4. 动效：入场、滚动视差、3D 视角变化、悬停、配色切换的动效自定——追求动感与炫酷，但必须可打断、不妨碍阅读；支持 prefers-reduced-motion 降级
5. 响应式：1440×900 与 390×844 两档不得横向溢出，触控目标 ≥44px
6. 提供统一测试接口 `window.__LAUNCH_TEST__`：
   - `snapshot()` → 可序列化对象，至少含 `{sections:[...], activeSection, activeColor, motionPaused}`
   - `goToSection(id)`、`setColor(name)`、`setMotionPaused(paused)`
   - 真实点击/触摸与测试接口必须走同一套状态
7. 零联网：禁 CDN、禁外部字体图片音频、禁 npm；唯一可选的本地依赖是预置的 `vendor/three.min.js`（r147，只读，不得修改）
